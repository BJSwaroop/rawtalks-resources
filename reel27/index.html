Counselling Process
Step-by-Step

Complete AP EAMCET counselling guide — Registration to reporting

6-Step Process
Complete Roadmap

Step 1: Registration

eapcet-sche.aptonline.in → Register → Pay ₹1,200 processing fee

Step 2: Certificate Verification

Visit helpline center → Bring originals + xerox → Documents verified

Step 3: Web Options

Enter 30-40 college+branch preferences online → More options = better chances

Step 4: Seat Allotment

System allots based on rank + preferences → 3 rounds (Round 1, 2, 3)

Step 5: Report to College

Visit allotted college → Submit originals → Pay fees

Step 6: Slide-up Option

After confirming seat → Select slide-up for better seat in next round

Expected Timeline

Counselling notification: July 2026
